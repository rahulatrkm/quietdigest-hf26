Slow and steady, on purpose

A reading shortcut.
Not an autonomous decision.

  1. Find the meaning. MiniLM embeds your sentences and the selected focus locally.
  2. Reduce repetition. A transparent relevance-and-novelty rule chooses different useful quotes.
  3. Keep the receipts. Every quote points back to the full source. Nothing is rewritten or sent automatically.

This is extractive selection, not generative summarization. It can miss nuance, important outliers, or a negation. Read the source before making a decision. No claim of complete coverage or professional advice.

      What runs locally, and what does not?

      Transformers.js 3.8.1 runs the quantized all-MiniLM-L6-v2 model on CPU through WebAssembly. A cold start downloads public assets, often tens of MB, so internet access is initially required. Once loaded, the open tab can run inference offline; a fresh reload is not guaranteed to work offline.

      The model revision is pinned. Notes never go to an inference API or local storage. Public asset providers still see ordinary network metadata. An explicit digest download creates a local file containing your selected quotes.

      Long sentences exceeding the model's 256-token limit are rejected with an actionable error rather than silently truncated. Identical sentences, ignoring whitespace and case, are deduplicated before inference. Sentences shorter than 12 characters are omitted and counted in the report.

      Original app: MIT. Model: all-MiniLM-L6-v2 (Apache-2.0). Inference: Transformers.js (Apache-2.0), ONNX Runtime (MIT).
